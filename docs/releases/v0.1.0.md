# Fleet Failure Atlas v0.1.0

The first public release turns four autonomous coding-agent failure mechanisms
into safe executable evidence.

## Included patterns

- **FFA-001 — Stale green CI evidence:** reproduce a green receipt attached to
  the wrong revision, detect the identity/coverage mismatch, and prove a repaired
  gate rejects it.
- **FFA-002 — Result-channel mismatch:** reproduce a completed worker ignored by
  a parent polling an undeclared artifact, then prove the declared channel is
  consumed directly.
- **FFA-003 — Concurrent queue update loss:** reproduce an accepted stable-key
  append lost by whole-file merging, then prove operation replay preserves it.
- **FFA-004 — Timezone-dependent test:** reproduce a calendar boundary from one
  fixed instant, detect naive time data, and prove an explicit-zone assertion.

## Also included

- dependency-free Python 3.11+ runner and validators;
- 12 fixture checks and unit tests;
- searchable GitHub Pages atlas plus machine-readable JSON;
- portable regression-review agent skill and human checklist;
- clean-room, safety, provenance, contribution, governance, and security policy.

All four entries are synthetic and labelled **hypothetical**. They demonstrate
mechanisms, not alleged incidents. Fixtures are offline and resource-bounded,
but the runner is not a security sandbox; review untrusted fixture changes.

Start with:

```bash
python3 atlas.py check
```
