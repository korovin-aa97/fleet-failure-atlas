# Fleet Failure Atlas v0.1.1

This patch release hardens the first public atlas after a clean-room release
audit.

## Highlights

- Search now finds stable IDs and all public metadata; lifecycle filters match
  both primary and secondary stages.
- Results are announced to assistive technology and the empty state is visible.
- FFA-001 proves the repaired gate rejects stale evidence *and* accepts valid
  fresh evidence.
- The runner fails closed on malformed or excessive output, invalid encoding,
  timeout, and unsafe fixture paths.
- CI adds strict typing, lint/format checks, a security scan, Python 3.14, and a
  Windows smoke lane. Workflow actions are pinned to immutable commits.

The runtime and test suite remain dependency-free on Python 3.11 or newer.
