# Fleet Failure Atlas v0.1.2

This patch release closes a macOS process-exit race in the bounded fixture
runner.

When an output-heavy fixture finished between the runner's final `poll()` and
its process-group signal, macOS could return `EPERM` instead of `ESRCH`. The
runner now re-checks the child and treats an already-finished process as cleanly
terminated. If the owned child remains alive, it falls back to terminating that
PID directly.

The release also includes the new README and social-preview visual that explains
the atlas as a four-step path: failure pattern, safe reproduction, deterministic
detection, and regression guard.

The runtime and test suite remain dependency-free on Python 3.11 or newer.
