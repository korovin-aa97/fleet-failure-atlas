# Fleet Failure Atlas v0.1.3

This release turns a public external report into a clean-room executable model
of the underlying failure pattern.

## FFA-005 — Fresh review, stale citation

An automated review can be fresh for the current commit while a positional
citation inside it still points to an earlier file layout. The new clean-room
fixture reproduces that split with synthetic text and commit identities:

```bash
python3 atlas.py run FFA-005 --mode reproduce
python3 atlas.py run FFA-005 --mode detect
python3 atlas.py run FFA-005 --mode regress
```

The detector resolves the citation against the exact revision and compares the
retrieved content with a stable rule ID and digest. The regression demonstrates
the repair invariant: identify the evidence by stable content, then render its
current line range for display.

The pattern is labelled `externally-reported` and links to the public discussion
and reproduction that motivated it. Its executable fixture is independent,
offline, bounded, vendor-neutral, and contains no copied repository content.

The runtime and test suite remain dependency-free on Python 3.11 or newer.
